# TrustFeed
An AI-powered platform that analyses images, videos, text, URLs and social media activity to identify potentially manipulated media, misleading information, scams, outdated content and coordinated disinformation campaigns.

The product is **TruthTrace AI**, for problem DL-SJBIT-HK26-GOVP006 at LAKSHYA 2026. Active development is on feature branches, so `main` shows little until final integration.
